Design & Analysis
of Algorithms

Rigorous study of algorithm design strategies, computational complexity, and the theoretical foundations that determine what computers can solve — and how efficiently.

Course Overview

Design and Analysis of Algorithms is a rigorous upper-division course that equips students with the tools to design efficient algorithms and reason formally about their correctness and performance. Topics span classical algorithm design paradigms — divide-and-conquer, dynamic programming, greedy algorithms — and computational complexity theory including NP-completeness. Students gain experience analyzing trade-offs between time, space, and problem constraints for real-world computing scenarios.

Topics Covered

  • Algorithm Analysis — asymptotic notation (Big-O, Ω, Θ), recurrences
  • Master Theorem — solving divide-and-conquer recurrences
  • Divide and Conquer — merge sort, quicksort, binary search, Strassen's algorithm
  • Sorting Algorithms — heap sort, counting sort, radix sort, comparison lower bounds
  • Greedy Algorithms — activity selection, Huffman coding, Kruskal's, Prim's
  • Dynamic Programming — memoization, tabulation, LCS, knapsack, matrix chain
  • Graph Algorithms — BFS, DFS, topological sort, SCC (Kosaraju/Tarjan)
  • Shortest Paths — Dijkstra's, Bellman-Ford, Floyd-Warshall
  • Minimum Spanning Trees — Kruskal's and Prim's algorithms
  • Network Flow — Ford-Fulkerson, max-flow min-cut theorem
  • String Algorithms — KMP, Rabin-Karp, string matching complexity
  • Computational Complexity — P vs NP, NP-completeness, reductions
  • Approximation Algorithms — vertex cover, TSP approximations

Learning Outcomes

  • Analyze algorithm time and space complexity using asymptotic analysis
  • Design efficient algorithms using divide-and-conquer, greedy, and DP paradigms
  • Implement and compare graph traversal and shortest path algorithms
  • Prove algorithm correctness using loop invariants and induction
  • Understand the boundaries of tractable computation (NP-completeness)
