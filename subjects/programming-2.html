Programming 2

Advanced programming concepts and object-oriented design — building scalable, maintainable software applications using modern programming paradigms.

Course Overview

Programming 2 builds upon introductory programming skills and transitions students into professional-grade software development. The course centers on Object-Oriented Programming (OOP) principles, data structures, file handling, and the development of complete applications. Students gain hands-on experience designing class hierarchies, implementing abstract data types, and solving complex programming challenges.

Topics Covered

  • Review of Programming 1 — control flow, functions, arrays
  • Object-Oriented Programming — classes, objects, encapsulation
  • Inheritance — single and multilevel, method overriding, super keyword
  • Polymorphism — method overloading, dynamic binding, interfaces
  • Abstraction — abstract classes, interfaces, design by contract
  • Exception Handling — try-catch-finally, custom exceptions
  • File I/O — reading/writing text and binary files, serialization
  • Data Structures — linked lists, stacks, queues, trees, hash tables
  • Searching and Sorting Algorithms — binary search, merge sort, quick sort
  • Collections Framework — ArrayList, HashMap, iterators
  • GUI Programming — event-driven programming, basic UI components
  • Introduction to Databases — JDBC / database connectivity from code

Learning Outcomes

  • Design and implement class hierarchies using OOP principles
  • Apply inheritance and polymorphism to build flexible software
  • Implement standard data structures from scratch
  • Handle runtime errors gracefully with exception handling
  • Build small-to-medium Java or Python applications with file persistence
