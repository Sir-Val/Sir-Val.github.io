Web Systems & Technology

From client-server architecture to full-stack web applications — understanding how the web works and how to build for it professionally.

Course Overview

Web Systems and Technology provides students with a comprehensive understanding of how the World Wide Web operates and how to develop standards-compliant web applications. The course covers web architecture, HTTP protocols, client-side technologies (HTML, CSS, JavaScript), server-side development, web APIs, and deployment. Students build progressive projects across the semester — culminating in a full-stack web application.

Topics Covered

  • Internet Architecture — DNS, IP, TCP/IP, HTTP/HTTPS protocols
  • Web Standards and the W3C — HTML5, CSS3, semantic markup
  • HTML — document structure, forms, tables, semantic elements, accessibility
  • CSS — selectors, box model, flexbox, grid, responsive design, media queries
  • JavaScript — DOM manipulation, events, fetch API, ES6+ features
  • Client-Server Model — AJAX, JSON, RESTful communication patterns
  • Server-Side Development — PHP or Node.js (Express) basics
  • Databases for Web — MySQL/SQLite integration, CRUD operations
  • Web APIs — consuming and creating REST APIs, authentication (JWT basics)
  • Web Security — XSS, CSRF, SQL injection prevention, HTTPS
  • Performance and Optimization — caching, minification, lazy loading
  • Web Hosting and Deployment — shared hosting, cloud (GitHub Pages, Heroku)
  • Introduction to Frameworks — brief survey of React / Vue / Angular

Learning Outcomes

  • Build semantic, accessible, standards-compliant HTML/CSS web pages
  • Write dynamic JavaScript for interactive user experiences
  • Create server-side logic that connects to a database
  • Design and consume RESTful APIs
  • Deploy a functional web application to a public host
