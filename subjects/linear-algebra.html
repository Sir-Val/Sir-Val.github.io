Linear Algebra

The mathematics of vectors, matrices, and linear transformations — powering everything from computer graphics and machine learning to signal processing and quantum computing.

Course Overview

Linear Algebra is a core mathematical discipline that underpins modern engineering, data science, and artificial intelligence. This course covers vector spaces, matrix operations, and linear transformations, with a strong emphasis on computational applications. Students will see how linear algebra connects to graphics rendering, neural network weight matrices, principal component analysis (PCA), and control systems.

Topics Covered

  • Vectors in ℝⁿ — operations, dot product, cross product, norms
  • Matrices — types, operations, transpose, inverse, determinant
  • Systems of Linear Equations — Gaussian elimination, row reduction, RREF
  • Vector Spaces — subspaces, basis, dimension, null space, column space
  • Linear Transformations — kernel, range, matrix representation
  • Orthogonality — orthogonal bases, Gram-Schmidt process, projections
  • Eigenvalues and Eigenvectors — characteristic polynomial, diagonalization
  • Symmetric Matrices and Quadratic Forms
  • Singular Value Decomposition (SVD) — overview and applications
  • Applications — computer graphics transformations, least squares regression
  • Introduction to Linear Algebra in Machine Learning (matrix operations in AI)

Learning Outcomes

  • Solve systems of linear equations using matrix methods
  • Compute matrix operations, inverses, and determinants efficiently
  • Understand vector spaces and linear independence concepts
  • Apply eigenvalue decomposition to engineering problems
  • Connect linear algebra theory to real-world computational applications
