Artificial Intelligence

An exploration of intelligent systems, machine learning, reasoning, and AI-driven problem solving for real-world engineering and computing challenges.

Course Overview

This course introduces students to the foundational concepts and modern applications of Artificial Intelligence (AI). Students learn to formulate AI problems, apply search and optimization techniques, and understand how machines can simulate intelligent behavior. The curriculum connects classical AI theory with contemporary machine learning and deep learning approaches.

Core Topics Covered

  • Introduction to AI — history, Turing test, and AI paradigms
  • Intelligent Agents — PEAS model, environment types, agent architectures
  • Search Algorithms — BFS, DFS, A*, greedy best-first, heuristic search
  • Adversarial Search — minimax algorithm, alpha-beta pruning, game trees
  • Knowledge Representation — propositional and predicate logic, ontologies
  • Expert Systems — rule-based systems, inference engines, forward & backward chaining
  • Machine Learning — supervised, unsupervised, reinforcement learning overview
  • Neural Networks — perceptrons, multilayer networks, activation functions
  • Natural Language Processing — tokenization, parsing, text classification basics
  • AI Ethics & Societal Impact — bias, fairness, accountability in AI systems
  • Applied AI Projects — chatbots, image classifiers, intelligent game agents

Learning Outcomes

  • Formulate real-world problems as AI search or optimization tasks
  • Implement and compare classic AI algorithms in Python or Java
  • Design simple expert systems and knowledge bases
  • Understand the pipeline of a supervised machine learning model
  • Critically evaluate ethical implications of AI deployment
