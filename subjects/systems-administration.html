Systems Administration
& Maintenance

Practical skills for managing, configuring, and maintaining operating systems and network infrastructure — the backbone of enterprise IT operations.

Course Overview

Systems Administration and Maintenance is a hands-on course that prepares students for real-world IT roles. Taught by Engr. Fabregas — an IT professional with over 20 years of enterprise IT service management experience — this course covers operating system installation, user and resource management, network services configuration, system monitoring, backup and recovery, and security hardening. Students gain practical lab experience using both Windows Server and Linux environments.

Topics Covered

  • Introduction to System Administration — roles, responsibilities, documentation
  • Operating System Installation — Windows Server and Linux (Ubuntu/CentOS)
  • User and Group Management — accounts, permissions, Active Directory basics
  • File System Management — disk partitioning, NTFS, ext4, quotas
  • Network Configuration — IP addressing, DNS, DHCP, gateway setup
  • Network Services — FTP, SSH, Telnet, HTTP/HTTPS server setup
  • Directory Services — Active Directory, LDAP fundamentals
  • System Monitoring — performance counters, logs, SNMP, alerting
  • Backup and Disaster Recovery — backup strategies, restore procedures, RTO/RPO
  • Security Hardening — firewall rules, patch management, antivirus, policies
  • Scripting for Administration — PowerShell and Bash automation scripts
  • Virtualization — VMware/VirtualBox basics, VM creation and management
  • IT Service Management Concepts — ITIL basics, incident & change management

Learning Outcomes

  • Install, configure, and maintain Windows Server and Linux systems
  • Manage users, groups, file permissions, and network services
  • Implement backup, recovery, and security hardening procedures
  • Write basic administration scripts using PowerShell and Bash
  • Apply ITIL-inspired best practices for IT service operations
